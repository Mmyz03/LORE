# LORE — AI-Powered Story Generation

LORE is an AI-powered story generation platform that creates unique stories based on a selected category or the user's own story idea. It uses AI to generate complete, creative stories with a cinematic reading experience.

## Features

* AI-powered story generation
* Category-based story presets
* Custom story prompts
* Adjustable story length
* Generate another unique version
* Listen to stories using text-to-speech
* Dark cinematic UI
* Responsive design for desktop and mobile

## Tech Stack

**Frontend**

* HTML
* CSS
* JavaScript

**Backend**

* Python

**AI**
